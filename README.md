# Valorant API

**Exploring Valorant: Agents & Maps**

A frontend web application that consumes the Valorant API to display all agents and maps with a clean, interactive, and user-friendly interface. This project was built as a solo frontend project to practice API integration, UI organization, and modern Vue-based development.

---

## 📖 Project Overview

This project showcases Valorant agents and maps in an intuitive layout, allowing users to explore detailed agent information, search content dynamically, and filter agents based on their roles.

- **Role:** Frontend Developer  
- **Project Type:** Solo Project  
- **Live Website:** https://valorant-yulsz.netlify.app/#/  
- **Source Code:** https://github.com/UlyssesTranquilino/Valorant-API-TS.git  

---

## ✨ Key Features

### 🔍 Search Functionality
- Quickly search for Valorant agents and maps.
- Results update dynamically as users type.
- Improves navigation and content discovery.

### 🧑‍🚀 Agent Details Page
- Displays detailed information for each agent.
- Includes agent roles, abilities, and descriptions.
- High-quality visuals for a more engaging experience.
- Helps users understand different agent playstyles.

### 🎭 Filter by Roles
- Filter agents by role:
  - Duelist  
  - Sentinel  
  - Controller  
  - Initiator  
- Category-based organization for easier browsing.
- Helps players find agents that match their preferred playstyle.

## 🛠️ Tech Stack

- **Vue.js** – Core frontend framework
- **Quasar Framework** – UI components and responsive layout
- **TypeScript** – Type-safe and maintainable code
- **Valorant Public API** – Data source for agents and maps
- **Netlify** – Deployment and hosting
